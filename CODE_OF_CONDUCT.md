# Code of conduct

Upbar uses the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## 1. Our standards

- Be respectful to all persons.
- Accept constructive criticism.
- Give help to new contributors.
- Do not use harassment, insults or personal attacks.

## 2. Report a problem

1. Send an email to josephgoksu@gmail.com.
2. Describe the problem and the persons that it affects.

Result: The maintainer reads all reports. The maintainer keeps each report confidential.
